# Library Management System

Ibukunoluwa Oluwashola · Student ID 301926692 · MIT 8103

This portfolio follows a small fictional library database. It covers members, books and loans, from the first table design to a proposal for storing loan events in a distributed system.

- [Portfolio 1: Database design](portfolio-1-database-design/) — Ten invalid test inserts were rejected; the sample data stayed unchanged.
- [Portfolio 2: Query optimisation](portfolio-2-query-optimisation/) — In the index test, median lookup time went from 2.26 ms to 0.276 ms, with the same results.
- [Portfolio 3: Transactions](portfolio-3-transactions-concurrency/) — A row lock prevented one of two concurrent updates from being lost.
- [Portfolio 4: MongoDB](portfolio-4-nosql/) — Four sample loan events were added and checked.
- [Portfolio 5: Distributed design](portfolio-5-distributed-cloud/) — A proposed setup only; no cloud system was deployed.
